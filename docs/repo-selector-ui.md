# 仓库选择器界面说明

## 设计灵感
参考 RustDesk 文件传输界面的设计理念，提供直观、高效的仓库选择体验。

## 功能特点

### 1. **直观的文件夹网格视图**
- 大图标，清晰的文件夹/仓库标识
- Git 仓库带有特殊图标和标签
- 悬停效果，拖拽支持

### 2. **面包屑导航**
- 快速导航到上级目录
- 点击任意层级跳转

### 3. **路径快速输入**
- 支持直接输入路径
- 回车键快速跳转

### 4. **批量选择功能**
- 双击选择/取消选择仓库
- 拖拽仓库到选择区域
- "添加当前文件夹所有仓库" 一键批量添加

### 5. **已选仓库列表**
- 实时显示已选择的仓库
- 显示仓库名称和完整路径
- 单独移除选项

### 6. **智能提示**
- 已选仓库数量统计
- 重复仓库自动去重
- 操作结果反馈

## 交互方式

### 文件夹操作
- **单击**：进入文件夹
- **双击**：选择/取消选择仓库
- **拖拽**：
  - 拖拽普通文件夹 → 进入
  - 拖拽 Git 仓库 → 添加到已选列表

### 快速操作
- 单击面包屑导航快速跳转
- 输入路径后按回车或点击"转到"
- 点击"添加当前文件夹所有仓库"批量添加

### 确认/取消
- 底部显示已选仓库数量
- "确定添加"按钮完成添加
- "取消"按钮关闭对话框

## 样式特点

### 浅色主题
- 网格背景：#f8fafc
- 仓库文件夹：渐变橙色背景
- 选中状态：蓝色边框 + 渐变背景
- 悬停效果：轻微上移 + 阴影

### 暗色主题
- 网格背景：#1e293b
- 仓库文件夹：深橙红色渐变
- 选中状态：深蓝色渐变
- 自动适配系统主题

### 使用示例

```typescript
import { createRepoSelectorDialog } from '@/components/common/repo-selector'

// 单选模式
const result = await createRepoSelectorDialog()
console.log(result) // string

// 多选模式（默认）
const results = await createRepoSelectorDialog({ multiple: true })
console.log(results) // string[]
```
